
# Flipkart E-Commerce Data Analysis

## Project Overview

This project performs exploratory data analysis on
Flipkart e-commerce product data.

## Objectives

- Data cleaning
- Missing value handling
- Duplicate detection
- Data type preprocessing
- Outlier analysis
- Data visualization
- Insight generation

## Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visualizations

1. Retail Price Distribution
2. Retail vs Discounted Price
3. Discount Percentage Distribution
4. Top 10 Brands
5. Product Rating Distribution
6. Flipkart Advantage Products

## Key Findings

- Product prices are highly right-skewed.
- Many products have substantial discounts.
- Retail and discounted prices have a strong positive relationship.
- Most products do not have available ratings.
- A small number of brands account for a large number of listings.
- Most products are not marked as Flipkart Advantage.
